> ## ComfyUI 设计师的高效率工作区插件
>
> **高效管理工作流、节点收藏与节点模板，用更顺手的编组方式整理复杂画布。**

ComfyUI-WorkspaceKit 是一个面向 ComfyUI 的工作区增强插件，集中工作流管理、节点收藏、模板复用和画布整理。

当前为 **公开测试版 0.2.4**。首次用于主力环境前，请备份重要工作流、用户设置、节点收藏和模板数据。

## 为什么需要 WorkspaceKit

当你的 ComfyUI 使用时间变长后，通常会遇到这些问题：

- 工作流越来越多，官方列表不方便长期整理。
- 第三方插件越来越多，节点来源、分类和常用节点很难管理。
- 常用的节点组合经常重复搭建，缺少一键保存和复用的方式。
- 复杂工作流画布越来越乱，需要更清晰的编组、标题和注释结构。
- 删除、移动、重命名工作流时，希望有回收站和恢复机制，避免误操作。

WorkspaceKit 的目标，就是把这些高频整理动作集中到一个更顺手的工作区里。

| 常见问题 | WorkspaceKit 的解决方式 | 带来的结果 |
| --- | --- | --- |
| 工作流数量太多 | **工作流2**：树状目录、搜索、拖拽、排序、最近记录 | 按项目整理，更快找到需要的工作流 |
| 节点难找、难记 | **节点2**：来源分类、搜索、拼音搜索、收藏分组 | 快速查找并建立常用节点库 |
| 节点组合重复搭建 | **模板**：保存节点位置与连接关系 | 常用结构一次保存，随时复用 |
| 大型画布结构混乱 | **编组增强 + 透明标题** | 建立更清晰的工作区域与层级 |
| 担心误删和迁移丢失 | **双层回收站 + 数据备份与迁移** | 更容易恢复、备份和转移 |

## 核心功能

WorkspaceKit 目前提供一个统一侧边栏入口，入口内包含三个内置标签，并可合并兼容扩展标签：

- **工作流2**：管理 ComfyUI 工作流目录中的工作流文件。
- **节点2**：浏览、搜索、收藏、分组和整理节点。
- **模板**：把已经连接好的选中节点保存为可复用模板，支持分组管理和模板回收站恢复。

同时，插件还包含两个画布辅助能力：

- **编组增强**：强化画布编组快捷键、标题栏样式设置和默认编组样式。
- **标题2**：用于给复杂工作流添加更清晰的视觉标题、区域说明和注释。

### 一个入口，管理核心创作资产

三个内置标签分别管理工作流文件、节点收藏和节点模板。兼容的外部标签可按用户设置合并或独立显示；已置顶的兼容标签存在时，可通过 `Shift+4` 打开。

### 把常用操作变成可复用资产

节点收藏和模板库将个人的常用节点、连接结构和整理习惯沉淀为可长期复用的创作资产。

### 不仅高效，也尽量可恢复

工作流和模板各自提供可恢复回收站；数据导入与写入官方收藏前会创建相应备份，降低整理和迁移时的误操作风险。

## 功能说明

### 工作流2

工作流2 面向“工作流文件管理”。它适合用来整理长期积累的大量 `.json` 工作流。

主要能力：

- 默认使用 ComfyUI 官方工作流目录。
- 树状文件夹管理，支持文件夹和子文件夹。
- 新建、重命名、拖拽移动工作流和文件夹。
- 支持拖到文件夹、展开的文件夹区域和根目录。
- 删除工作流时先进入 WorkspaceKit 回收站，可恢复后再决定是否移到系统回收站。
- 支持排序、自定义顺序、优先显示文件夹。
- 支持最近工作流历史记录，并可在设置中调整显示数量。
- 支持搜索、清空搜索、刷新和点击名称直接打开工作流。
- 支持打开工作流所在位置。
- 支持文件夹图标和颜色个性化。
- 支持 `Ctrl + 点击` 有子层级的文件夹或分组，递归展开或折叠。

> **提示：** 该操作作用于树形文件夹 / 分组本身，不适用于“打开 / 浏览”“收藏 / Comfy / 第三方”等区域标题；搜索框有内容时，为了展示匹配路径，折叠结果不会在界面上隐藏。

![工作流2：目录、排序与拖拽说明](Preview/a1.png)

![工作流2：回收站与恢复说明](Preview/a1.1.png)

**快捷入口：** `Shift+1` / `Shift+W`

| 搜索框右侧按钮 | 作用 |
| --- | --- |
| 新建文件夹 | 在当前浏览位置创建文件夹。 |
| 新建工作流 | 创建空白工作流。 |
| 导入 | 从本地选择并导入工作流。 |
| 排序 | 按名称、修改时间或自定义顺序显示；可设置优先文件夹。 |
| 回收站 | 查看已删除工作流；再次点击返回工作流列表。 |

高级用户可以选择自定义工作流根目录。如果使用该功能，请只选择专门用于 ComfyUI 工作流的文件夹，不要选择磁盘根目录、桌面、下载目录或大型项目目录。

### 节点2

节点2 面向“节点查找、收藏和分组”。它适合安装了大量第三方节点、官方节点浏览器已经不够顺手的用户。

主要能力：

- 从 ComfyUI 当前节点信息中读取可用节点。
- 按 **Comfy** 和 **扩展** 区分节点来源。
- 扩展节点按插件来源整理，减少第三方节点混在官方分类里的情况。
- 支持节点搜索、模糊搜索和拼音搜索。
- 支持收藏节点、收藏分组和收藏子分组。
- 支持节点拖拽到收藏分组。
- 支持收藏节点在分组之间拖拽整理。
- 支持节点拖拽到画布。
- 支持点击节点后，再点击画布放置节点。
- 支持节点预览卡片。
- 支持与 ComfyUI 官方收藏进行导入 / 导出；写入官方收藏前会自动备份设置文件。
- 对缺失的第三方节点进行弱显示，不会静默删除。
- 支持节点缓存，便于大型节点库更快显示首屏内容。

![节点2：收藏与官方收藏同步说明](Preview/a2.png)

**快捷入口：** `Shift+2` / `Shift+N`

| 搜索框右侧按钮 | 作用 |
| --- | --- |
| 新建收藏分组 | 创建节点收藏分组。 |
| 预览模式 | 切换完整 / 紧凑节点预览。 |
| 排序 | 调整节点显示顺序。 |
| 收藏管理 | 导入、导出、备份和恢复官方收藏与 WorkspaceKit 收藏。 |

### 模板

模板功能面向“节点组合复用”。它适合保存常用的节点小结构，例如一组已经连好的加载、预处理、控制、输出或后处理节点。

主要能力：

- 使用 `Alt+C` 将当前选中的节点保存为模板。
- 保存模板时保留节点相对位置和连接线。
- 支持模板拖拽到画布。
- 支持单击模板进入待放置状态，再点击画布放置。
- 支持模板分组和子分组。
- 支持模板搜索、排序、重命名、删除、回收站和恢复。
- 支持模板 hover 预览。
- 支持模板行内重命名按钮；右键菜单包括重命名、放置到画布中心和删除。
- 支持模板删除和模板分组删除的行内确认，删除后可从模板回收站恢复。

![模板：预览、重命名与右键菜单说明](Preview/a3.png)

![模板：回收站与恢复说明](Preview/a3.1.jpg)

**快捷入口：** `Shift+3` · **保存模板：** `Alt+C`

| 搜索框右侧按钮 | 作用 |
| --- | --- |
| 新建模板分组 | 创建模板分组。 |
| 保存选中节点为模板 | 保存当前选中且已连接的节点。 |
| 排序 | 调整模板显示顺序。 |
| 回收站 | 查看、恢复或永久清理已删除模板。 |

测试阶段为保证兼容性，模板数据仍使用 ComfyUI 用户目录下现有的 Workspace2 兼容存储位置；升级到 WorkspaceKit 后，已有模板数据仍可继续使用。建议定期备份重要模板数据。

### 编组增强

编组增强面向“复杂画布整理”。它让 ComfyUI 的编组更接近常见设计软件的使用习惯。

主要能力：

- 使用 `Ctrl+G` 从选中节点创建 WorkspaceKit 编组。
- 使用 `Shift+G` 解除一个或多个已选 WorkspaceKit 编组框，不会删除节点。
- 使用 `Ctrl/Meta + 左键` 切换忽略；使用 `Alt + 左键` 切换禁用。
- 使用 `Shift + 左键` 将 WorkspaceKit 编组加入或移出临时多选。
- 支持在空白画布 `Ctrl + 拖拽`，在保留 ComfyUI 原生框选的同时框选 WorkspaceKit 编组。
- 对已选 WorkspaceKit 编组按 `Delete`，只删除编组框，节点和连线会保留。
- 右击编组标题栏打开样式设置。
- 保存当前编组样式为默认预设之一。
- 支持设置编组边距、边框、阴影、动画等视觉参数。
- 编组数据保存到工作流中。

如果 `Ctrl+G` 与 ComfyUI 官方快捷键冲突，请先在 ComfyUI 快捷键设置中移除或修改官方绑定，或在 WorkspaceKit 设置中关闭相关开关。

### 标题2

标题2 是一个轻量的画布标题 / 注释节点，适合给大型工作流添加区域标题、说明和视觉分隔。

默认样式：

- 字号：24
- 背景：透明
- 圆角：15

### 数据备份与迁移

WorkspaceKit 支持导出和导入插件自身管理的数据，适合迁移节点收藏、模板、文件夹元数据和设置。导入前会自动创建备份；工作流文件和可重新生成的节点缓存不包含在导出包中。

## 安装

### 通过 ComfyUI Manager / Registry 安装（推荐）

在 ComfyUI Manager 中搜索 `WorkspaceKit` 或 `comfyui-workspacekit`，安装后重启 ComfyUI。

### 通过 Git 安装

进入 ComfyUI 的 `custom_nodes` 目录：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ZiYao00/ComfyUI-WorkspaceKit.git
cd ComfyUI-WorkspaceKit
python -m pip install -r requirements.txt
```

完成后重启 ComfyUI。Windows Portable 请在其根目录使用：

```powershell
.\python_embeded\python.exe -m pip install -r .\ComfyUI\custom_nodes\ComfyUI-WorkspaceKit\requirements.txt
```

## 依赖

推荐安装：

```text
send2trash
```

请在 ComfyUI 使用的 Python 环境中安装依赖，用于更完整的跨平台系统回收站支持：

```bash
pip install -r requirements.txt
```

不要在不了解 ComfyUI Python 环境的情况下随意更新依赖。

## 数据安全与备份

### 两层回收站

WorkspaceKit 有两层回收站：

- **WorkspaceKit 回收站**：工作流删除后的可恢复回收站；模板另有独立的可恢复库回收站。
- **系统回收站**：操作系统自己的回收站。

在 Windows 上，WorkspaceKit 已内置系统回收站 fallback。其它平台的系统回收站功能依赖 `send2trash` 以及当前桌面环境的支持。

### 首次使用前建议

WorkspaceKit 会移动、重命名和整理工作流文件。首次在主 ComfyUI 环境中使用前，建议备份：

- ComfyUI 工作流目录。
- ComfyUI 用户设置。
- 重要节点收藏数据。
- 重要模板数据。

## 5 分钟快速开始

1. 从侧边栏打开 WorkspaceKit，使用 `Shift+1`、`Shift+2`、`Shift+3` 切换工作流、节点和模板。
2. 在工作流2中新建文件夹，再把一个工作流拖入其中。
3. 在节点2搜索常用节点，并拖入收藏分组。
4. 在画布选中一组已连接节点，按 `Alt+C` 保存为模板。
5. 选中节点后按 `Ctrl+G` 创建第一个 WorkspaceKit 编组。
