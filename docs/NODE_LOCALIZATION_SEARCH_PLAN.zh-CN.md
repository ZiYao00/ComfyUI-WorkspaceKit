# 节点本地化显示与搜索计划

状态：运行时标题覆盖与 DD Translation 双语检索已完成；后续仅做版本升级回归。

## DD Translation 英文检索别名（已完成）

已确认 DD Translation 会将浏览器运行时的 LiteGraph 标题改写为译名，但其
`/agl/get_translation` 数据表仍以原节点名为键。因此，对“忽略多框”这类节点，
WK 需要在**当前浏览器内存**中补充原英文名作为检索别名，不能修改或重新下载
`/object_info`。

前两批已完成：适配器以原英文节点名为键补充对应中文译名；反向“译名 → 原名”仅接受
唯一映射，同一译名对应多个原名时直接放弃反查，避免错误命中。节点面板首次打开后才会
一次性、最多等待 3 秒地可选加载 DD Translation 翻译表；成功后仅重建 WK 内存中的节点
显示/搜索投影。不轮询、不写入服务端快照或 IndexedDB；未安装、关闭或请求失败时静默
回退原有搜索。

真实页面验收中发现 pinyin-pro 对“略”等字会输出 `ü`；共享搜索索引现同时保留
带 `ü` 与普通键盘输入的 `u` 版本，例如 `hulüeduokuang` 和 `hulueduokuang` 都可命中。

**2026-08-04 真实页面验收：** 测试服务的 WK【节点】面板中，rgthree 的显示名为
“忽略多框”；搜索“忽略多框”、“hulueduokuang”与“Fast Groups Bypasser”均返回该节点。
验收过程中先发现中文译名未进入搜索字段，已通过“英文原名 → 中文译名”的正向别名
修正；未通过页面性能对象读取网络清单（自动化安全上下文未暴露 `performance`），但本批
新增网络路径仅为一次可选的 `/agl/get_translation`，代码中没有新增 `/object_info` 调用。
范围：WK 节点面板的标题显示、中文/英文搜索与拼音搜索；不改动 ComfyUI 节点定义本身。

## 已确认事实

- WK 的可复用节点快照来自服务端 `/object_info`，当前标题直接采用原始 `display_name`。
- ComfyUI 画布和官方节点管理器在中文环境可能显示另一份前端运行时标题。
- WK 的拼音搜索底层可正确匹配中文；若 WK 索引中只有英文标题，则无法搜索中文或拼音。

## 目标与边界

1. 中文、英文、节点 type、别名和拼音均可搜索。
2. 不识别或依赖某个翻译插件的名称；只消费当前浏览器最终可用的运行时标题。
3. 原始快照保持跨浏览器、跨语言稳定，绝不把翻译后的标题写回服务端缓存。
4. 不抓取官方节点管理器 DOM；DOM 文本不是稳定 API。
5. 无法从运行时定义取得翻译标题时，安全回退原始标题，不猜测翻译结果。

## 三层数据模型

```text
服务端原始节点快照
  type / 原始 display_name / 分类 / 输入输出
        ↓
当前浏览器显示覆盖层（非持久化或仅本浏览器）
  type → 当前运行时标题、原始标题
        ↓
搜索索引
  type + 原始标题 + 当前标题 + 别名 + 分类 + 对应拼音
```

显示覆盖层的生命周期仅属于当前浏览器和当前语言；原始快照签名变化、语言变化或运行时标题指纹变化时，覆盖层与搜索索引失效并重建。

## 分批实施

### 第 1 批：只读探针与证据

- 为指定节点采集 `/object_info` 原始标题、LiteGraph 已注册节点标题、构造函数 `nodeData` 标题，以及可见官方节点定义容器中的同 type 记录。
- 输出来源、字段路径和候选标题；不改变 WK 显示、搜索、缓存或网络请求。
- 使用 `CheckpointLoaderSimple` 和一个被翻译的第三方节点验证。

验收：能明确指出当前中文标题的真实来源；若所有稳定来源都只有英文，则记录为“仅 DOM 翻译”，不进入第 2 批。

**2026-08-04 基线结果：** 测试服务 `http://127.0.0.1:8190/` 的自动化浏览器为英文环境。`CheckpointLoaderSimple` 在以下三处均为 `Load Checkpoint`：`object_info.display_name`、`LiteGraph.registered_node_types.title`、`LiteGraph.registered_node_types.nodeData.display_name`。探针已证明 LiteGraph 构造器标题可稳定读取；中文/翻译插件环境尚未采样，因此第 2 批尚未开始。

### 第 2 批：显示覆盖层与双语搜索

- 仅接入第 1 批确认稳定的运行时字段。
- 节点行优先显示运行时标题；搜索同时保留原始与运行时标题。
- 继续按需缓存拼音字段，禁止启动时为全量节点预生成拼音。

验收：中文环境能搜索中文/全拼/首字母/英文；英文环境仍能搜索英文；节点缓存请求量不增加。

**2026-08-04 实施：** 已仅接入第 1 批确认的 `LiteGraph.registered_node_types` 标题字段。原始标题保留为 `rawTitle`，并与运行时标题同时进入搜索别名；收藏节点显示优先采用实时标题。中文运行时的真实验收仍待第 3 批前完成。

### 第 3 批：失效、回退与真实环境验收

- 语言切换或标题指纹变化时，仅重建显示/搜索层，不刷新 `/object_info`。
- 验证客户端中文、翻译插件中文、英文、无翻译标题四种情况。
- 对大节点库核对首开、首次搜索、重复搜索时间，以及 `/object_info` 请求次数。

**2026-08-04 实施：** 节点面板打开/重绘时会比较已注册节点的标题指纹，并在首次打开后延迟复核一次。发生变化时仅清除 WK 的内存节点显示/搜索投影后重绘；不会请求、清空或写入 `/object_info` 与 IndexedDB 缓存。客户端中文与翻译插件中文的真实验收仍待执行。

**2026-08-04 中文环境验收：** 当前中文前端中，`CheckpointLoaderSimple` 的 LiteGraph 标题为 `Checkpoint加载器（简易）`，WK 节点面板和收藏列表均显示该名称；搜索 `jiazai` 与 `load checkpoint` 均能显示该节点。验证期间浏览器资源记录中的 `/object_info` 请求数为 `0`。

**2026-08-04 运行时变化验收：** 在测试页面中临时将该节点的 LiteGraph 标题改为 `WK Runtime Title Test`，离开并回到【节点】面板后可见该测试标题；还原原始中文标题后再次重绘也恢复正常。两次重绘均无 `/object_info` 请求。测试仅改动了浏览器内存，已在结束前恢复；这验证了标题变化的失效机制，但没有改写 ComfyUI 的语言设置。

## 已知风险与规避

| 风险 | 规避 |
|---|---|
| 翻译插件只修改 DOM | 不抓 DOM；安全回退原始标题，必要时做经过验证的专用适配。 |
| 插件晚于 WK 改标题 | 在节点面板首次打开后作一次延迟复核，标题变化才重建覆盖层。 |
| 翻译后同名 | 保留 type 和分类副信息，type 始终为唯一身份。 |
| 跨浏览器污染 | 翻译覆盖层不写入服务端原始快照。 |
| 大节点库搜索卡顿 | 标题扫描轻量；拼音字段按需生成并缓存。 |
