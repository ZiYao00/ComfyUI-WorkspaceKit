# README 内容核对清单

本清单用于维护公开 README 的事实边界。功能或截图发生变化时，先更新
本清单，再修改中英文 README，避免把已移除功能或未验证承诺写回首页。

## 当前确认

- 发布版本以 `pyproject.toml` 为唯一来源；当前为 `0.2.4`。
- 中文和英文 README 都必须说明插件仍处于公开测试阶段。
- 模板行提供重命名和删除操作；模板右键菜单提供重命名、放置到画布中心
  和删除，**不再提供“复制模板名称”**。
- 工作流与模板都具有独立的可恢复回收站；系统回收站属于工作流文件的
  后续操作，模板不会写入系统回收站。
- Layout 的合并入口属于可选集成，不应在 WorkspaceKit 首页把它描述为
  WorkspaceKit 的固定内置第四标签。

## 写作规则

1. 不将正在验证的性能目标表述为确定性能数据。
2. 公开截图中的箭头、红框和快捷键叠层可以作为刻意的教学标注；只有
   开发期调试控件才不得被当作公开功能。
3. 功能清单必须同时匹配中英文 README；语言可以不同，事实必须相同。
4. README 图片使用 `docs/screenshots/` 的正式素材名称；`Preview/` 只保留
   拍摄候选和审阅参考。
5. 每次发布前检查版本徽章、安装命令、Registry 状态、回收站说明和快捷键。

## 本次替换前必须修正的文字

| 候选 README 文字 | 发布版处理 |
| --- | --- |

| Layout 兼容标签可通过 Shift+4 打开 | 保留为“已置顶且兼容的扩展标签存在时”。 |
| 截图可直接展示现有状态 | 当前五张 Preview 截图已获确认，可作为带教学标注的 README 素材。 |
