## 拍摄规则

1. 使用统一的主题、缩放比例、窗口宽度和语言。
2. 避免真实用户名、客户名称、本地绝对路径、模型私有名称及其它隐私数据。
3. 一张图只说明一个主要功能；不要同时展开多个无关菜单。
4. 红框、箭头和键盘叠层可用于突出一个明确操作，是当前 README 的教学
   表达方式；避免仅保留无法理解的开发调试信息。
5. 明天录制的 GIF 用于展示连续操作；静态教学图继续承担功能解释。
6. PNG/JPG 以清晰可读为优先；GIF 过大时降低帧率或尺寸。
